# Progress Belajar PostgreSQL

Repo ini berisi latihan query, struktur database, dan data contoh dari proses belajar PostgreSQL menggunakan pgAdmin 4.

## Cara menyimpan latihan dari pgAdmin 4

1. Buka **Query Tool** dan tulis query.
2. Pilih **File > Save As**.
3. Simpan latihan ke folder `queries/`, misalnya `queries/01-select-dasar.sql`.
4. Jalankan `git add .`, `git commit -m "Tambah latihan"`, lalu `git push`.

## Struktur folder

- `queries/` — query latihan harian
- `schema/` — perintah membuat tabel, relasi, dan database
- `data/` — data contoh yang aman untuk dibagikan

Jangan menyimpan kata sandi atau data produksi di repository ini.
